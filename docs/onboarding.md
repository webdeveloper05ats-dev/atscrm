# ATS CRM Onboarding

## Who Can Access What

- Super Admin: Full access including Backup & Health and Demo Reset.
- Admin/Branch Team: No access to Backup & Health or Demo Reset.
- HR/Marketing/Front Office/Staff: No access to Backup & Health or Demo Reset.
- All logged-in roles: Can open Onboarding Guide.

## Daily Workflow

1. Capture lead or enquiry updates.
2. Complete follow-up actions and status changes.
3. Convert qualified enquiries to draft/registration.
4. Update payments and targets where applicable.
5. Review reports before end-of-day closure.

## Super Admin Utilities

- Backup & Health:
  - Run health checks
  - Export database
  - Export uploads
- Demo Reset:
  - Clears transactional demo tables
  - Keeps master setup data (roles/users/menus/permissions)
  - Requires explicit confirmation text
